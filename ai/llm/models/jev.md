# Jev

Notes as of 2026-11-09. Launch details come from secondary coverage quoting the press release; the press release itself was not read, and the current signup status was not confirmed with TypeSafe AI.

## What is it

Jev is a "System One" decision model from TypeSafe AI ([typesafe.ai](https://typesafe.ai)). It's a model, not a personal agent like [OpenJarvis or OpenClaw](jarvis.md).

* takes an input and a schema, returns structured decisions as typed JSON
* used for tasks like classifying, routing, and scoring
* the jevai.net FAQ says it is not a replacement for an LLM

## When it came to market

**Early access launch: 2026-09-15**, when TypeSafe AI came out of stealth and announced $40 million in seed funding. No general public release was found as of 2026-11-09, and jevai.net still refers to a future "public launch".

| Date | Event | Evidence |
|---|---|---|
| 2026-09-11 | JavaScript/TypeScript SDK v0.5.7, first public release | single source |
| 2026-09-15 | early access launch, waitlist at typesafe.ai | several sources |
| 2026-09-18 | listed on OpenRouter | single source |
| 2026-10-16 | latest update to the version 1.14 article (image input, Box outputs, long context, all experimental) | jevai.net only |

## jevai.net is not the official site

* its footer calls it "an unofficial project maintained by community enthusiasts", not affiliated with TypeSafe AI
* the domain was registered on 2026-09-17, two days after the launch
* its "Try Jev API" button goes to a third-party reseller, DefAPI, with referral tracking
* its price of $0.084 per million input tokens is labeled a "site price", so don't rely on it
